# Privacy Quest

A small, responsive website that teaches everyday privacy and online-safety habits through an interactive five-scenario quest, a three-case digital-rights court mini-game, and a dated newsletter-style briefing on selected privacy, safety, copyright, digital ownership, games preservation, and archive issues. The court game and briefing are educational, not legal advice; rights vary by location.

The Privacy Dispatch links legal summaries to government or legislative sources, labels campaign positions, and identifies the jurisdiction for each legal example. Its current issue is marked as last reviewed on 21 October 2026; it is a dated snapshot, not a live news feed.

## Run it

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript and has no build step or package dependencies. The game runs locally and does not collect or store player information.

## Project files

- `index.html` — page content, games, and Privacy Dispatch issue
- `styles.css` — responsive visual design
- `script.js` — game scenarios, scoring, and feedback
